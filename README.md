# CodeLoop

CodeLoop is a small, dependency-free shadow typing practice tool for learning code. Paste any code into the practice field and repeat it until the syntax feels familiar.

## Practice loop

1. Paste or write code in the practice field.
2. Click **开始练习**.
3. Type it character by character.
4. Finish the sample to automatically start the same round again.

The app runs entirely in the browser. No account or backend is required.
